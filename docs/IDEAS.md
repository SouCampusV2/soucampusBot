# Идеи — бэклог вне текущей фазы

Сюда — то, что не входит в фазы `ROADMAP.md`. Идея, уехавшая в работу,
помечается 🟢 и остаётся здесь: видно, чем замысел стал.

## 🔴 ИИ пишет посты в Discord из админки сайта (владелец, 27.10)

В админке сайта, рядом с кнопками «Post to Discord» (портфолио, премейд, фри
билдс, анонсы): кнопка **«Write with AI»**. ИИ (Claude API) получает данные
постройки (название, размер, версия, цена, картинки, теги) и **прошлые посты
владельца** как образец стиля — и пишет черновик: заголовок, текст с эмодзи,
список ссылок. Владелец правит в том же редакторе с превью и публикует сам —
ИИ ничего не отправляет без клика. Можно: «перепиши короче / веселее»,
перевод, варианты заголовка. Место — сайт (`SouCampusWeb`, `FirstTry`):
там редактор, данные построек и история `discord_posts`. Ключ API — только на
сервере сайта (Vercel env), не в браузере. Записано и в
`docs/phase4/SITE-PROMPT.md` (дополнение 27.10, вечер) для сессии по сайту.

## 🔴 Проверка покупателей BuiltByBit и выдача ролей (из BUSINESS-NOTES 19.08)

У BBB есть бот, который проверяет покупку и выдаёт роль на своём сервере —
законный способ собрать в свой Discord аудиторию из их трафика (ссылаться на
себя на BBB нельзя, правила 5.2 и 5.10). Сначала узнать условия тарифа BBB Pro:
может, хватит их бота, и свой не нужен.

## 🔴 Ранний доступ для Discord

`BUSINESS.md`: преимущество своего канала — не скидка, а то, чего нет на BBB.
Роль «Early access» + анонс новой карты в Discord раньше площадок.

## 🔴 Оплата ссылкой Stripe из тикета

Менеджер жмёт «Request payment» → ссылка Stripe Checkout → вебхук сайта
отмечает оплату. Только после того, как живой Stripe включат на сайте
(`FirstTry/docs/STRIPE.md`). До этого — ручное подтверждение.

## 🔴 Предоплата этапами

Крупные заказы (400×400 = €600 за две недели) — 50% вперёд, 50% по сдаче.
Две кнопки подтверждения вместо одной.

## 🔴 Шаблоны ответов менеджера

`/reply template:<имя>` — частые ответы (сроки, цены, что такое schematic)
одной командой.

## 🔴 Напоминание клиенту об отзыве

Через 3 дня после завершения без отзыва — одно напоминание в ЛС. Отзывы
продают (в `BUSINESS.md` → «Что показал рынок» ссылка на разницу в
продажах с отзывами и без).
